# Henry's I.T Services – Web App

A modern, mobile-friendly Progressive Web App (PWA) for **Henry's I.T Services** (https://henrysitservices.co.uk).

## Features

- Official logo integrated in header, footer and as app icon
- Clean, professional dark theme optimised for mobile and desktop
- One-tap **Call** and **WhatsApp** buttons
- Clear presentation of all services (Mac/PC, Networking, CCTV, Cloud, Relocations)
- Contact details, hours, and address
- Simple enquiry form that opens the user’s email client
- Installable as a PWA on phones and desktops (“Add to Home Screen”)
- Works offline for the main pages once visited

## How to use / deploy

1. Open `index.html` in any modern browser, or
2. Upload the whole folder to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.)
3. On mobile: open the site → browser menu → “Add to Home Screen” / “Install app”
